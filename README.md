# Marketplace

Projeto Django inicial do Projeto 5 — Marketplace, da disciplina Construção de Backend do IESB.

## Ambiente de desenvolvimento

Crie e ative o ambiente virtual, instale as dependências listadas em `requirements.txt` e execute `python manage.py runserver`.

A chave secreta local fica no arquivo ignorado `.secret_key`. Também é possível defini-la na variável de ambiente `DJANGO_SECRET_KEY`.
